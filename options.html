翻译引擎

通用

使用方法

  • Alt+T：翻译当前选中文字
  • Alt+Shift+T：翻译当前页面正文
  • 选中文字后右键 → 「翻译选中的英文」
  • 点击工具栏图标可手动输入翻译

常见问题

翻译结果有时不准，如何提升？

免费引擎（腾讯 TransMart / 有道）是网页版接口，质量为基础机翻水平。切换到 DeepSeek（大模型，语义理解最佳）或百度（传统机翻中较优）可显著提升准确度，只需在上方填入对应 Key。

为什么有些页面无法整页翻译？

Chrome 扩展无法翻译 chrome://、Chrome Web Store、以及部分禁止注入脚本的网页。
